# Secure Multi-Site Enterprise Network

## Overview
Enterprise network designed and implemented using Cisco Packet Tracer.

## Features
- VLAN Segmentation
- Inter-VLAN Routing
- OSPF
- EIGRP
- Route Redistribution
- Site-to-Site VPN
- NAT/PAT
- Extended ACLs
- Layer 3 Etherchannel
- hsrp protocol
- DHCP
- AAA Authentication
- Port Security
- DHCP Snooping
- SPAN Monitoring
- SSH Management
